# توصيلات حاضنة الطفل

## المكونات
| المكون | النوع |
|--------|-------|
| Arduino Uno | وحدة التحكم |
| DHT11 | مستشعر درجة حرارة الحضانة والرطوبة |
| MLX90614 | مستشعر درجة حرارة جسم الطفل (أشعة تحت حمراء) |
| LCD 16x4 I2C | شاشة العرض |
| Relay Module (2ch) | للتحكم في المروحة والسخان |
| زر 1 (UP) | رفع درجة الحرارة المستهدفة |
| زر 2 (DOWN) | خفض درجة الحرارة المستهدفة |

---

## التوصيلات

### DHT11
| DHT11 | Arduino |
|-------|---------|
| VCC   | 5V      |
| GND   | GND     |
| DATA  | Pin 7   |

### MLX90614 (I2C)
| MLX90614 | Arduino |
|----------|---------|
| VCC      | 3.3V    |
| GND      | GND     |
| SDA      | A4 (SDA)|
| SCL      | A5 (SCL)|

### LCD 16x4 I2C
| LCD I2C | Arduino |
|---------|---------|
| VCC     | 5V      |
| GND     | GND     |
| SDA     | A4 (SDA)|
| SCL     | A5 (SCL)|

> ملاحظة: MLX90614 و LCD يشتركان في نفس خط I2C (A4/A5)

### Relay Module
| Relay | Arduino | يتحكم في |
|-------|---------|----------|
| IN1   | Pin 8   | المروحة (FAN) |
| IN2   | Pin 9   | السخان (HEATER) |
| VCC   | 5V      |          |
| GND   | GND     |          |

> الريلاي يعمل بمنطق Active LOW (إشارة LOW = تشغيل)

### الأزرار
| الزر | Arduino | الوظيفة |
|------|---------|---------|
| BTN_UP   | Pin 2 → GND | رفع درجة الحرارة +0.5°C |
| BTN_DOWN | Pin 3 → GND | خفض درجة الحرارة -0.5°C |

> الأزرار تعمل مع INPUT_PULLUP (لا تحتاج مقاومات خارجية)

## شرح شاشة LCD

```
┌────────────────┐
│Amb:37.2°C H:55%│  ← درجة حرارة الحضانة + الرطوبة
│♥Baby:36.8°C OK │  ← حرارة جسم الطفل + الحالة
│Set:37.0°C ↑/↓  │  ← الدرجة المستهدفة + أزرار الضبط
│Status: NORMAL  │  ← حالة النظام (FAN ON / HEAT ON / NORMAL)
└────────────────┘
```

### حالات الطفل
| الحالة | درجة حرارة الجسم |
|--------|-----------------|
| OK     | 36.0 – 37.5°C   |
| COLD   | أقل من 36.0°C   |
| HOT    | أكثر من 37.5°C  |

### حالات النظام
| الحالة   | الشرط |
|----------|-------|
| FAN ON   | حرارة الحضانة > الهدف + 0.5°C |
| HEAT ON  | حرارة الحضانة < الهدف - 0.5°C |
| NORMAL   | الحرارة ضمن النطاق المقبول |

---

## نطاق الضبط
- أدنى درجة مستهدفة: **35.0°C**
- أعلى درجة مستهدفة: **40.0°C**
- خطوة الضبط: **0.5°C**
- القيمة الافتراضية: **37.0°C**
